UWCC M0 spike

Throwaway test page. Everything runs on this device; nothing is uploaded. Run the steps, then send the report back.

Idle

1. Built-in test (no files needed)

Checks the device, codec support, a synthetic video round trip (encode, then decode → shader → encode) and a synthetic photo export. Takes one to a few minutes.

2. Your own videos

Pick clips straight from your cameras (GoPro, phone, …). Each is decoded, run through a colour shader, re-encoded and written to MP4.


3. Your own photos

Pick full-resolution photos. Each is decoded, corrected in tiles on the GPU and encoded as JPEG.

4. Folder write access (desktop Chrome / Edge)

Pick a folder; the page writes a small test file into it, reads it back and deletes it again.
